# 算数 文章題｜テーマ選択版

ブロック冒険・動物・アイドル・食べ物から、問題に登場する人物や物を選べる算数文章題アプリです。

- たし算・ひき算・かけ算・わり算を複数選択できます。
- ペンと絵文字ブロックを使って考えられます。
- かけ算・わり算では、問題画面で枠の表示／非表示を切り替えられます。
- 利用者ごとに学習記録を保存します。

## GitHub Pagesで公開する手順

1. GitHubで `word-problem-theme-choice` という名前のリポジトリを作成します。
2. このZIPを解凍し、`index.html`、`.nojekyll`、`README.md`をリポジトリの一番上にアップロードします。
3. リポジトリの「Settings」→「Pages」を開きます。
4. 「Deploy from a branch」を選び、Branchを `main`、フォルダーを `/(root)` にして保存します。
5. 公開後のURLは `https://icoaplus.github.io/word-problem-theme-choice/` です。

## データ保存について

利用者の名前、設定、学習記録は、使用している端末のブラウザ内に保存されます。別の端末や別のブラウザには自動で移りません。
